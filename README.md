# \# ServiceNowCM Connector

# 

# Enterprise integration connector between ServiceNow and OpenText Content Manager.

# 

# \## Current capabilities

# 

# \- ServiceNow connection management

# \- Content Manager connection management

# \- Dynamic ServiceNow metadata discovery

# \- Content Manager record type and field discovery

# \- Configurable integration mappings

# \- Multi-page synchronization

# \- SQL-backed synchronization tracking

# \- Resume/checkpoint support

# \- Sync failure tracking

# 

# \## Technology

# 

# \- .NET 8

# \- ASP.NET Core

# \- Entity Framework Core

# \- SQL Server

# \- ServiceNow REST API

# \- OpenText Content Manager SDK
